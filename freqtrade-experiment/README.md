# Freqtrade Experiments

Two independently owned Hyperliquid/Freqtrade projects share this collection:

- [`hmm-slope-experiment/`](hmm-slope-experiment/) — the original
  `HmmSmaSlopeV2` research, paper execution, and live monitoring. The run is
  stopped and parked.
- [`mean-variance-paper/`](mean-variance-paper/) — the collaborator-owned
  signed mean-variance research and paper monitor. It remains a research
  candidate pending cross-cycle validation.

The mean-variance project reuses the original project's ignored market-data
cache and Freqtrade environment, but owns its strategy, config, analysis,
results, agent instructions, and monitoring code.
