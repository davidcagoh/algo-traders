# AI Methods

Cross-cutting machine-learning papers referenced by repository concepts.

- [Maximum Likelihood Reinforcement Learning](2602.02710-maximum-likelihood-reinforcement-learning.pdf)
  concerns RL training under correctness feedback.
- [History Echoes](2603.03308-history-echoes.pdf) studies persistence induced by
  conversational history; it informs safeguards against path-dependent ideation.
- [LeWorldModel](2603.19312-leworldmodel.pdf) supplies an example of
  random-projection distributional regularization used by the wiki's stability
  notes.

These are not trading-strategy evaluation papers.
