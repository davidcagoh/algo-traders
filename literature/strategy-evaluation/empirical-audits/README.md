# Empirical Audits

Studies that test whether strategy evidence survives deployment-like scrutiny.

- [Backtest regime and live performance](2604.18821-backtest-regime-live-performance.pdf):
  peer benchmarks, launch regime, and pro-forma-to-live decay.
- [Negative-results evidence audit](2607.19453-negative-results-evidence-audit.pdf):
  chronology, purges, execution timing, artifacts, and post-hoc diagnostics.
- [Crypto microstructure patterns](2602.00776-explainable-crypto-microstructure.pdf):
  purged validation, fee sensitivity, and tail-event execution testing.

These papers provide useful protocols but do not all have peer-reviewed status;
see [`../_index.md`](../_index.md).
