# Literature

Shared primary material that crosses project boundaries.

- [`_index.md`](_index.md) is the authoritative inventory, including provenance
  and links to project-specific collections.
- [`quant-trading/`](quant-trading/) contains broad trading context.
- [`crypto-markets/`](crypto-markets/) is a flat, paper-centric collection of
  crypto/perpetual-market PDFs and source notes.
- [`strategy-evaluation/`](strategy-evaluation/) contains reusable evaluation
  methods, empirical audits, foundational inference, and surveys.
- [`ai-methods/`](ai-methods/) contains reusable agent and machine-learning
  methods referenced by the wiki.

The [`../quant-research-agent/`](../quant-research-agent/) automates discovery
and maintenance but does not own source material. Durable synthesis belongs in
[`../wiki/`](../wiki/) after review.

Recurring searches are configured in [`search-config.yml`](search-config.yml)
and recorded in [`search-log.md`](search-log.md).
