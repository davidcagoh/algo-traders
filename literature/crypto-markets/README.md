# Crypto Markets Literature

Primary sources and source-specific notes maintained as one flat,
paper-centric collection.

- [`_index.md`](_index.md) is the authoritative manifest. Every selected source
  is recorded even when no PDF can be mirrored.
- PDFs and Markdown notes share a stable-ID-first filename where possible.
- A note is not a substitute for the paper and must state its PDF or access
  status. Record-only notes remain here when no legal PDF can be mirrored.

The scheduled discovery workflow is configured in
[`../../quant-research-agent/paper-search-trigger.md`](../../quant-research-agent/paper-search-trigger.md).
